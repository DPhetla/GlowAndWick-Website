## 🌐 Project Domain Concept & Overview
Glow & Wick is a premium boutique e-commerce showcase application crafted using semantic HTML5 structures, responsive layout properties inside CSS3 stylesheets, and native JavaScript client-side inputs validator methods. The project presents an immersive sensory product grid, physical mapping systems, video logs, and a dynamic customization onboarding client sheet.

## 🗺️ Five-Page Core Architecture Map
1. `index.html` - Homepage welcoming consumers with background summaries and a structural YouTube video tour.
2. `about.html` - Brand heritage summary profile detailing raw soy wax material data metrics.
3. `products.html` - Signature collection product listing showcasing responsive grid cards and item properties.
4. `enquiry.html` - Custom orders validation questionnaire backed up by dynamic interactive alert containers.
5. `contact.html` - Regional flagship storefront mapping center showing hours of physical commerce operations.
